Core Capabilities

Everything you need to
launch a city AI guide

Not a toy demo. AINA is a grounded, tested architecture that prevents AI hallucination, calculates real geo-distances, and runs 100% on free cloud tiers.

🧠
Zero-Hallucination AI Grounding
Unlike generic chatbots, AINA fetches verified Supabase records — descriptions, opening hours, entry fees, and coordinates — and injects them as factual context into Google Gemini before responding. The AI can only claim what the database actually contains.
📍
Built-in Geospatial Distance
Native Haversine trigonometry in the backend computes real straight-line distances (km) between landmarks. Users can ask "What's nearby?" or "What's within walking distance?" and get truthful proximity answers — no third-party mapping API required.
💬
Multi-turn Conversation Memory
In-memory session store tracks up to 40 turns per conversation. Users can ask follow-ups like "Why is that significant?", "Plan a route from there", or "What food is nearby?" and the context carries across the dialogue naturally.
🗺️
Interactive Leaflet Map Portal
Full React 19 + Leaflet web app with interactive map pins, category filters (Heritage, Spiritual, Art, Hidden Gems), Food discovery, user bookmarks, visited-place tracking, Supabase Auth, and an admin dashboard for content management.
⚡
Next.js 14 Chat Frontend
Clean App Router chat UI with Tailwind CSS, rich Markdown rendering for AI responses, auto-scrolling, error recovery, and conversation-ID persistence. Configured for zero-cost static export to Vercel.
🧪
700+ Lines of Automated Tests
Comprehensive Pytest suite covering endpoint contracts, Gemini error handling (502/503), session isolation, data formatters, and context injection — all with mocked external dependencies. No API keys needed to run tests.
🐳
One-Click Docker Deployment
Production-ready Dockerfile pre-configured for Hugging Face Spaces (port 7860). Runs on Render, Fly.io, and Railway equally well. The frontend deploys to Vercel with a single environment variable.
🗃️
Ready-to-Run SQL Schema & Seed Data
Standalone schema.sql creates all tables (places, food items, explorations, profiles) with Row Level Security. sample_data.sql seeds 5 authentic heritage monuments and 4 culinary specialties so you can test immediately — no empty database.

Quick Start

Up and running in
under 60 minutes

Four steps. No complex infrastructure. All on free tiers.

①
Create free accounts
Sign up for Google AI Studio (Gemini API key) and Supabase (free project). Both take under 5 minutes.
②
Run database scripts
Paste schema.sql then sample_data.sql into the Supabase SQL Editor. Click Run. Done.
③
Add .env and start backend
Copy .env.example to .env, insert your keys, run uvicorn aina.app:app --reload.
④
Deploy to cloud
Push Dockerfile to Hugging Face Spaces, import frontend to Vercel. Live with HTTPS in minutes.
